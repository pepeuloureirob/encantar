# Encantar Cerimonial 💍

Sistema web desenvolvido em Flask para gerenciamento de eventos, feedbacks e apresentação online do cerimonial.

---

# Funcionalidades

## Site público

- Página inicial;
- Sobre nós;
- Serviços;
- Eventos realizados;
- Galeria através de links do Google Drive;
- Avaliações de clientes;
- Botão WhatsApp;
- Layout responsivo.

---

# Painel Administrativo

O administrador pode:

- Fazer login;
- Visualizar estatísticas;
- Cadastrar eventos;
- Editar eventos;
- Excluir eventos;
- Aprovar feedbacks;
- Excluir avaliações.

---

# Tecnologias utilizadas

- Python 3.12
- Flask
- SQLite
- SQLAlchemy
- Flask Login
- HTML5
- CSS3
- JavaScript
